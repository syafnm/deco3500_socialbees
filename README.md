## Prototype & Access

You can evaluate our prototype in two ways: 

### 1. Live Online Demo (for quick review)
Our prototype is fully deployed and accessible online via Netlify:
* **URL**: https://ubiquitous-gumdrop-50d615.netlify.app/

### 2. Local Static File (for offline testing)
Since our prototype is built with pure HTML/CSS/JS, you can run it entirely locally without installing any development environment (no`npm install` needed): 
1. **Download/Clone** this repository to your computer.
2. Open the project folder and locate **`index.html`**.
3. **Double-click `index.html`** to open it directly in your web browser.
